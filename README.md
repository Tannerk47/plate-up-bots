pie bot is a simple pathing ai on a set kitchen layout using .json files 
.json files can be generated from the 'kitchen GUI' place the items in the virtual kitchen
mark what recipe you're cooking(it will alocate any add on recipies for sides in the future) and where it will start
the keystroke for the bot to make a food is ctrl+f (spammable) any add on recipies will be ctrl+F+*number*
